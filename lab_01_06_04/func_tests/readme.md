# Тесты для лабораторной работы №1, задача 6, вариант 4

## Входные данные
Координаты отрезка и точек в двумерном пр-ве

## Выходные данные
1 - если точка принадлежит отрезку, в противном - 0

## Позитивные тесты
- 01 - координаты точки не совпадает с координатами точек отрезка
- 02 - координаты точки не совпадает с координатами точек отрезка
- 03 - координаты точки совпадает с координатой первой точки отрезка

## Негативные тесты
- 01 - буквы среди чисел в еачале ввода
- 02 - недостаточное кол-во чисел для задания координат
- 03 - буквы среди чисел в конце ввода
