# Тесты для лабораторной работы №1, задача 8, вариант 2

## Входные данные
Целое число A, длиной 4 байта и целое число N

## Выходные данные
Двоичное число, полученное циклическим сдвигом числа A влево на N позиций

## Позитивные тесты
- 01 - произвольное небольшое A и N
- 02 - N равен 0
- 03 - N равен 32
- 04 - большое значение A
- 05 - большое значение A

## Негативные тесты
- 01 - буквы вместо чисел в начале ввода
- 02 - буквы вместо чисел в конце ввода
- 03 - отрицательное N
