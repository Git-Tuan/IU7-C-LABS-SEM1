# Тесты для лабораторной работы №1, задача 7, вариант 4

## Входные данные
Некоторое число x, |x| < 1 и точность eps

## Выходные данные
Значение функции s(x), f(x), абсолютная и относительная погрешность

## Позитивные тесты
- 01 - x равен нулю
- 02 - x равен произвольному числу, |x| < 0
- 03 - x равен отрицательному числу
- 04 - eps очень маленький
- 05 - x близок по модулю к 1
## Негативные тесты
- 01 - буквы вместо чисел
- 02 - |x| > 1
- 03 - буквы вместо чисел
- 04 - пустой ввод
- 05 - большое значение eps
